# Finance manager

- Criar um APP para gestão de gastos. No APP o usuário inicialmente vê um painel com seu controle mensal atual (atualizado diariamente). No controle mensal ele verifica os gastos já feitos, categorias e valores. É possível também ver as próximas despesas já planejadas. Existem opções para baixar arquivo de extrato de despesas do dia seja de conta corrente, cartão de crédito ou outro. Na tela de importação do arquivo de despesas o usuário pode selecionar o arquivo no dispositivo, ou informar um endereço com os dados, e o sistema baixa os dados que são arquivados em um banco. Existe a opção de conciliar o extrato com dados de SMS enviados pelo banco, comprovantes PDF ou que o usuário pode scanear com a câmera. Após este processo existe uma tela de conciliação para a confirmação e ajuste dos dados importados. Após confirmação o usuário volta para a tela principal com o controle mensal atualizado. Existem opções para incluir uma conta bancária, cartão ou online para conciliação e monitoramento. Há uma opção de verificar os gastos por categoria e outra de planejar um projeto que irá envolver gastos. O usuário também pode baixar o planejamento para imprimir em PDF ou exportar para um arquivo de dados CSV.

1. Quem vai usar este app?

    - Inicialmente pessoal. Futuramente abrangerá empresas.

2. Sobre o recurso de planejamento de projetos com gastos, o que você precisa rastrear?

    - Comparativo entre previsto x realizado, Cronograma de despesas previstas com data, Orçamento por categoria dentro do projeto, Gastos por categoria

3. Para a conciliação de extratos, quais formatos de arquivo você usa?

    - OFX / CSV (bancos brasileiros como Nubank, Itaú, Bradesco), PDF de extrato bancário ou cartão, Arquivo de texto ou outro formato

4. Tipos de gráficos

   - Gráfico de pizza ou donut com percentual por categoria

5. Como entrar dados de despesas e receitas

   - O sistema lê os SMS pendentes de leitura do aparelho do usuário por padrão. É possível colar/digitar o texto para criar uma nova despesa manualmente

6. Sobre o visual, como será
   
    - Colorido e amigável (ícones por categoria, estilo app de finanças pessoais)
